# ✈️ GrowTravel - Landing Page

![GitHub Repo Size](https://img.shields.io/github/repo-size/Lucasgyn94/growtravel-gh-pages?style=for-the-badge)
![GitHub last commit](https://img.shields.io/github/last-commit/Lucasgyn94/growtravel-gh-pages?style=for-the-badge)

Projeto desenvolvido durante o módulo de **Fundamentos do Desenvolvimento Front-End** da formação Growdev. O objetivo foi aplicar conceitos de HTML5 e CSS3 para criar uma página de agência de viagens responsiva e moderna.

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica.
* **CSS3:** Estilização, Flexbox e Grid.
* **Google Fonts:** Tipografia personalizada.
* **Font Awesome:** Ícones sociais e de navegação.

## 🛠️ Funcionalidades

- [x] Design Responsivo (Desktop/Mobile).
- [x] Seção de destinos em destaque.
- [x] Formulário de contato/newsletter.
- [x] Rodapé com links sociais.
